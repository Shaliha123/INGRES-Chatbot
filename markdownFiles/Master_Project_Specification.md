# AI-Driven ChatBOT for INGRES as a Virtual Assistant

---

## Project Version

Version: 2.0

Status: Planning & Reconstruction

---

# Project Objective

Develop a modern AI-powered virtual assistant for the Integrated Groundwater Information Retrieval System (INGRES).

The system should provide groundwater-related information through a conversational chatbot while also functioning as a complete groundwater information management platform.

---

# Primary Goals

- Build a scalable web application
- Replace keyword-based chatbot with AI
- Store all application data in MongoDB Atlas
- Develop REST APIs using FastAPI
- Integrate Gemini AI for intelligent responses
- Support document management
- Support knowledge retrieval
- Build an Admin Dashboard
- Build Analytics Dashboard
- Maintain a clean and modular architecture
