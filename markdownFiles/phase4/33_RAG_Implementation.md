# Retrieval Augmented Generation

## Objective

Provide AI responses using project knowledge instead of relying only on the language model.

---

## Workflow

User Question

↓

Search MongoDB Knowledge Base

↓

Retrieve Relevant Documents

↓

Prepare Context

↓

Send Context + Question to Gemini

↓

Receive AI Response

↓

Store Chat History

↓

Return Response

---

## Benefits

- More accurate responses
- Context-aware answers
- Reduced hallucinations
- Easier knowledge updates
