# MongoDB Collections

## users

Purpose:
Store registered users.

Main Fields

- name
- email
- password
- role
- created_at
- updated_at

---

## chat_history

Purpose:
Store conversations.

Main Fields

- user_id
- question
- answer
- timestamp

---

## knowledge_base

Purpose:
Store groundwater knowledge.

Main Fields

- title
- category
- content
- keywords

---

## documents

Purpose:
Store uploaded documents.

Main Fields

- filename
- path
- uploaded_by
- upload_date

---

## analytics

Purpose:
Store dashboard statistics.

---

## logs

Purpose:
Store system logs.

---

## settings

Purpose:
Store application settings.
